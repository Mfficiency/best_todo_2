# Changelog

Newest version first. `dart run tool/bump_version.dart <version> "<entry>"`
prepends a new section here and updates pubspec.yaml — keep this order.

## [0.1.0] - 2026-07-26
- Initial template: main menu with dynamic title & version, searchable
  single-page settings, theming (system / light / dark + minimalist), date &
  time formats, selectable start page, notification preferences (quiet hours,
  default delay), About / Changelog / App Logs / Startup Times / Test Results,
  versioned backup export & import, and an automated screenshot process.
