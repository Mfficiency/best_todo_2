# Changelog

## [1.0.0] - 2026-11-13
- First version of BestToDo Lite: the plain BestToDo task list for older phones (Android 7 and up). Today, Tomorrow, Next week and the other tabs, search, the archive, synced with the same Todoist account. Settings, Changelog, About and automatic updates included; no reminders, alarms, widgets or tools
